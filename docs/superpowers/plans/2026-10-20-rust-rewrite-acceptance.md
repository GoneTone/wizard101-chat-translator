# Rust 版實機驗收清單（v1.0.0 發佈前）

用 `_exe_test\Wizard101ChatTranslator.exe` 跑。每項寫的是「做什麼 → 應該看到什麼」，打勾表示通過；不通過的請記下項目編號，並附上 `app.log`。

需要特別準備的項目標在括號裡：**（雙開）** 要開兩個遊戲客戶端，**（斷網）** 要能暫時拔網路，**（多螢幕）** 要有第二顆或不同縮放的螢幕。沒有環境的可以跳過，跳過的請註明。

標 ★ 的是第 5 段改過、只有自動測試、還沒在實機上看過的行為，請一定要測。

- [ ] 1.3 overlay 的 ✕ 關閉：程式結束，遊戲不受影響（不當機、聊天照常）。
- [x] 1.4 再開一次，改用工作列按鈕右鍵 → 關閉視窗、以及 overlay 在前景時按 Alt+F4：都正常結束，遊戲不受影響。
- [ ] 1.5 縮成泡泡後，從泡泡的工作列按鈕關閉：同樣正常結束。

## 5. 發話（翻譯輸入框）與貼上

- [ ] 5.1 遊戲在前景時按呼出快捷鍵（預設 Ctrl+Space）：輸入框出現在遊戲聊天框旁邊並取得焦點；按住快捷鍵不放時，要等放開才出現。
- [ ] 5.2 輸入中文按 Enter：翻成英文後打進遊戲聊天框（不會自動送出 Enter）；打字期間切走前景會中止。
- [ ] 5.3 空白時按 Enter 或 Esc：輸入框關閉，焦點回到遊戲。
- [ ] 5.4 譯文超過 80 字：顯示錯誤，原文保留在輸入框。
- [ ] 5.5 開著輸入框時，遊戲關閉聊天框：輸入框隱藏；再開聊天框（自動顯示開啟時）：輸入框連同草稿回來。
- [ ] 5.6 「自動顯示輸入框」關掉：遊戲開聊天框時不會自動跳出輸入框，用快捷鍵仍可以叫出。
- [ ] 5.7 前景不是遊戲時按快捷鍵：不會有反應（輸入框已開著時只會重新對焦）。
- [ ] 5.8 單獨的 Ctrl 或 Shift 組合被吞掉時，不會切換輸入法或打開選單。
- [ ] 5.9 遊戲聊天框開著時按 Ctrl+V：剪貼簿文字以單行打進遊戲；聊天框沒開時，多行文字逐行送出並按 Enter。
- [ ] 5.10 「Ctrl+V 攔截」關掉：Ctrl+V 交給遊戲自己處理。
- [ ] 5.11 （雙開）輸入框翻譯用的是「目前前景客戶端、目前分頁」的上下文；自動顯示只跟著前景客戶端。

- [ ] 6.3 Esc、右鍵、或只點一下不拖：取消，焦點回到遊戲。
- [ ] 6.4 快速連按兩下框選快捷鍵：不出現選取畫面，遊戲保持在前景。
- [ ] 6.5 標題列 ⛶：遊戲不在前景時也能開始框選；遊戲沒開時，在游標處顯示錯誤卡片。
- [ ] 6.6 遊戲最小化時按 ⛶：顯示錯誤卡片。

- [ ] 6.14 框選中文與英文混排、多行文字：辨識結果合理；框到沒有字的地方顯示空結果。
