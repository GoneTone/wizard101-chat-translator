## Global Constraints（每個 task 都適用）

- 先讀 `CLAUDE.md`。實作註解預設一行、只寫 WHY，三行是上限不是目標；docstring 一行摘要；CJK 全形標點；log 一律英文、沿用既有前綴；不可寫死語言；API 金鑰不可進 log。
- 行號是審查當下的參考值，動手前以實際程式為準；描述與程式不符時以程式為準並在回報說明。審查列的「某處也有一份」若實際查不到或語意其實不同，就不要硬合併，回報說明。
- 改到行為的項目（標「行為」）先寫會失敗的測試、確認失敗，再修。純重構靠現有測試把關，**不改既有測試的斷言語意**（只允許因搬移／改名而改 import 或呼叫方式）。
- 不新增只有一個實作的 trait、不新增抽象層；共用函式放在被依賴方向較低的模組。被合併掉的舊函式、常數、測試輔助一律刪除，不留轉手包裝。
- 刻意不同的不要合併：Gemini 只認 200、OpenAI 模型清單非 2xx 回 `Unexpected("HTTP {status}")`（`models_redirect_is_an_unexpected_status` 釘住）、各家 `request_body`／重試策略／prompt cache log、`repr_str`、stub bytes、各種 log 去重器（RepeatLimiter／first_failure／remember 語意不同）。
- 測試不可碰真實桌面、鍵盤 hook、剪貼簿或執行中的遊戲；不可啟動 GUI 或截圖。新的整合測試輔助放 `tests/common/` 或 `tests/it/` 既有模組；會切換全域介面語言的測試維持獨立檔。
- 每個 task 結束前：`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、完整 `cargo test` 各跑一次，全綠才 commit。迭代時只跑聚焦測試。
- Commit：英文 conventional commits（`refactor(...)`／`fix(...)`／`test(...)`），可分多個；結尾附派工說明給的 attribution 兩行。只 `git add` 實際改到的檔案，不用 `git add -A`。不 push。

## Task 1：已經不一致的小 bug（行為）

1. **熱鍵顯示與解析拆法不同**：`src/ui/settings/widgets.rs` `keycaps()` 以 `", "` 分段、`'+'` 分鍵；`src/input/keys.rs` `parse_hotkey` 用 `STEP_SEP`／`KEY_SEP` 正規式，且單一字元的熱鍵視為一個鍵。在 keys.rs 加 `pub fn split_hotkey(hotkey: &str) -> Vec<Vec<&str>>`（單字元規則、兩個正規式都在這裡），`parse_hotkey` 與 `keycaps` 都改用它，`keycaps` 只負責字首大寫。測試：`"ctrl+a,b"` 顯示為兩段、`"+"` 顯示為一個 `+` 鍵帽。
2. **空白壓縮三份**：`src/translation/errors.rs` `one_line` 與 `src/reader/markup.rs` 結尾那段相同（`split(pystr::is_space)`、去空、以空格接）；`src/ui/input_box.rs` `submit` 用 std `split_whitespace`，不認 `\x1c`–`\x1f`。把 `one_line` 移到 `src/py/pystr.rs`（Python 的 `" ".join(s.split())`），三處都改用；更新 `errors.rs`、`clients/mod.rs`、`clients/claude.rs` 等的 import。測試：輸入框送出含 `\x1c` 的文字時被壓成空格。
3. **數值欄位解析兩份**：`src/config/mod.rs` `parse_float`／`parse_int` 用 std `trim()`；`src/ui/settings/fields.rs` 的 +/− 步進器用 `pystr::strip` 自己再解析一次。`parse_float` 改用 `pystr::strip`、設為 `pub(crate)`，步進器改呼叫它；`parse_int` 一併改用 `pystr::strip`。測試：`"\x1c5"` 存檔時被接受（與步進器一致）。
4. **整理 app.log 時直接覆寫**：`src/logs/files.rs` `prepare_log` 用 `std::fs::write` 覆寫整個檔，寫到一半當機會截掉要匯出的 log。改用 `util::write_atomic`（`out` 由 String 建出，是合法 UTF-8；用 `String::from_utf8` 或直接保留 String 避免多餘轉換）。既有 log 測試照舊通過即可。
